Foxbyte Labs is a small workshop for apps, websites, desktop tools, and experiments. The work is handcrafted, useful, and a little curious — annoying problems and “I wonder if…” moments, turned into things that actually work.

Built by Marcell. Small ideas build big things.

## In the workshop

**[F.F.S](https://ffs.foxbytelabs.co.za/)**
Local-first personal finance. Transactions, reports, goals, and a way to plan ahead.
[Web app](https://ffs.foxbytelabs.co.za/) · [In the Den](https://den.foxbytelabs.co.za/sections/ffs.html)

**[StreamForge](https://den.foxbytelabs.co.za/sections/streamforge.html)**
Windows stream schedule builder, with Steam and RAWG search and Discord announcements.

**[What Was I Doing](https://den.foxbytelabs.co.za/sections/wid.html)**
A personal Windows time tracker. Start, stop, add a manual entry, and read the report.

**[The Huntress Cookbook](https://hcbw.foxbytelabs.co.za/)**
Gluten-free, onion-free, IBS-conscious recipes, read by chapter.
[Website](https://hcbw.foxbytelabs.co.za/) · [Mobile](https://den.foxbytelabs.co.za/sections/huntresscookbook-mobile.html)

**[Active Huntress](https://den.foxbytelabs.co.za/sections/active-huntress.html)**
An offline workout checklist with history, trends, and backup.

**[FoxFill](https://den.foxbytelabs.co.za/sections/foxfill.html)**
Privacy-first form filling from a local profile. Scan, review, then fill.
